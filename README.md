<p align="center"><b>Catminefy</b> is desktop app for Windows and Linux which includes tools for designing and creating content for Minecraft: Java Edition</p>

## Features

![JSoN &lt;=&gt; YAML](https://raw.githubusercontent.com/iamtowvee/catminefy/refs/heads/main/.repo/imgs/json-yaml_preview.png)

<p align="center"><b>JSoN & YAML Converter</b> can convert YAML syntax to JSoN and vice versa</p>

---

![Gradient Generator](https://raw.githubusercontent.com/iamtowvee/catminefy/refs/heads/main/.repo/imgs/gradient-generator_preview.png)

<p align="center"><b>Gradient Generator</b> can generate gradients in <b><img src="https://raw.githubusercontent.com/iamtowvee/catminefy/refs/heads/main/.repo/imgs/7_green.svg?raw=true&v=0" height="18" style="display:inline; vertical-align:middle;" /></b> different formats and can include up to <b><img src="https://raw.githubusercontent.com/iamtowvee/catminefy/refs/heads/main/.repo/imgs/10_green.svg?raw=true&v=0" height="18" style="display:inline; vertical-align:middle;" /></b> colors for one gradient, and also has 30+ gradient presets</p>

---

![Check Your Server Activity](https://raw.githubusercontent.com/iamtowvee/catminefy/refs/heads/main/.repo/imgs/CYSA_preview.png)

<p align="center"><b>Check Your Server Activity (CYSA)</b> can check the server status, its status relative to you (how many of 4 packets arrived without errors, a fully accessible server = 4), online players, the maximum number of players, the server's MOTD, whether there is a whitelist, whether a license is required, the port being used, the server's TPS (Ticks Per Second), and more using only the server address (IP, IP:port, Domain, or Domain:port format) to obtain information. A network connection is required to use this feature.</p>

---

![Customized Text](https://raw.githubusercontent.com/iamtowvee/catminefy/refs/heads/main/.repo/imgs/custom-text_preview.png)

<p align="center"><b>Customize Your Text (CYT, Cyt Editor)</b> is a built-in text editor with extensive functionality for text formatting: text formatting, coloring (including HEX and RGB colors), emoji (there is a special menu, emoji are displayed correctly even in Minecraft without modifications)</p>
