  > CAMERAS
   =========

     >> ЧТО ЭТО?
       ==========
        Плагин для Minecraft: Java Edition 1.21.11 (Paper/Spigot/Bukkit)

     >> КАК УСТАНОВИТЬ?
       =================
        1. Установите последнюю версию "cameras-VERSION.jar" (https://github.com/iamtowvee/cameras/releases/latest)
        2. Установите зависимости (Vault, Citizens)
        3. Положите все скачанные файлы в папку "plugins/" сервера
        4. Запустите сервер, чтобы появилась папка "plugins/cameras/"
        5. Готово!
